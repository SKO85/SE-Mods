# BUG-260612.39: Script.cs setter wrappers throw on read-only-published properties

## Status: Open
## Severity: Low
## Version: v2.5.6
## Found In: Script audit 2026-06-12 — `SKO-Nanobot-BuildAndRepair-System-Script/Script.cs` (RepairSystemHandler setters)

## Description
The mod registers some properties without a setter when the matching server
setting is fixed (`Terminal.cs` `CreateProperty(control, readOnly)`):
`AllowBuild` (AllowBuildFixed), `WeldMode` (welding disallowed), `Mode`/`WorkMode`
(only one mode allowed), `UseIgnoreColor`/`UseGrindColor` (color fixed), janitor
switches, `CollectIfIdle`, `PushIngotOreImmediately`, area sliders. The script's
property setters call `SetValue*` unguarded — on such servers a user script that
writes one of these kills the PB instead of being a no-op.

The shipped script only reads these properties, so this affects user-written
control code only.

## Root Cause
SE throws when calling `SetValue` on a property registered without a setter; the
script wrappers assume read-write.

## Fix
Wrap the setter loops in try/catch (per entity), or document the behavior in the
script header / companion-script docs. Cosmetic alongside: bump the script
version header (currently `v2.5.4 - 22.05.2026`) when the script next changes.
