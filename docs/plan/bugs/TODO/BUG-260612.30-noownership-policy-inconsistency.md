# BUG-260612.30: IsProtectedFromGrinding — NoOwnership policy differs between player-zone and admin-zone branches

## Status: Open
## Severity: Low
## Version: v2.5.6
## Found In: REVIEW-260612.1 #L14 — `Handlers/SafeZoneHandler.cs:574, 590-606`

## Description
The zone-block branch treats `NoOwnership` targets as grindable; the admin-zone branch (`SafeZoneBlockId == 0`) only allows Owner/FactionShare, and the fall-through relation check then marks unowned blocks protected. Result: unowned debris inside a grinding-allowed ADMIN zone is protected, while the same debris inside a grinding-allowed PLAYER zone is grindable. Possibly intentional (admin zones stricter) but undocumented and surprising.

## Root Cause
Two branches written at different times with different relation whitelists.

## Fix
Confirm the intended policy, align the branches (or keep the difference deliberately), and document it in a comment + the Grinding docs page.
