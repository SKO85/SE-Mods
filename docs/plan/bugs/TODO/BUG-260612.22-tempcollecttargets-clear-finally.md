# BUG-260612.22: _TempCollectTargets not cleared on exception or Close — pins entity references

## Status: Open
## Severity: Low
## Version: v2.5.6
## Found In: REVIEW-260612.1 #L6 — `NanobotSystem.Collecting.cs:72`, `NanobotSystem.Init.cs:261-268`

## Description
The buffer's comment promises "cleared after each pass so entity references aren't pinned", but the trailing `Clear()` sits inside the `try` — an exception in `ServerDoCollectFloating` leaves the buffer populated (the `finally` only profiles), and `Close()` clears the other temp lists but not this one. A throw on the last pass before block removal pins closed entities for the instance lifetime. Same exception path also skips the deferred `ChangeHash()` (cosmetic sync delay).

## Root Cause
Cleanup not exception-safe; field missed in the Close cleanup list.

## Fix
Move the `_TempCollectTargets.Clear()` into the `finally`, and add it to the `Close()` cleanup alongside the other temp lists.
