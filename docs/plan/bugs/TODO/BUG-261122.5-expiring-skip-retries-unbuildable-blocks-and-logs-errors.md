# BUG-261122.5: Expiring projected-build skip retries permanently unbuildable blocks and repeats Error log lines

## Status: Open
## Severity: Medium
## Version: v2.5.6
## Found In: follow-up check on BUG-261122.1/.2 (commit 932b23f) — `NanobotSystem.Welding.cs:838-845` (promotion), `:968` (`LogProjBuildSilentFail`)

## Description
Since BUG-261122.2 a skipped projected block is retried after 5 min with a fresh 3 strikes (the fail counter is
removed on promotion). For blocks that can never be built — missing DLC (`CheckMissingDlcs`), world/PCU limits
of the owner, a placement the game keeps refusing — every BaR now spends 3 `proj.Build` calls per block every
5 minutes, forever. Each of those failures also goes through `LogProjBuildSilentFail`, which logs at **Error**
(the default server log level) once per minute per BaR. A server with a DLC-blocked blueprint and 20 BaRs gets a
steady stream of Error lines that never stops.

## Steps to Reproduce
1. Survival, owner without a DLC; projector with a blueprint that contains a DLC block; several BaRs.
2. Watch the server log for 15 minutes: `projected build left no block; reason=unknown` keeps coming back every
   5 minutes per BaR.

## Root Cause
BUG-261122.2 made the skip expire but kept the original 3-strike re-entry, and the BUG-261122.1 diagnostic was
sized for a one-off investigation, not for a steady state with retries.

## Fix (proposed)
- After an expired skip, retry with **one** strike: keep the counter at `PROJ_BUILD_MAX_SILENT_FAILS - 1` instead
  of removing it, so a block that still fails goes straight back to the 5-min skip (1 call per block per 5 min).
- Log at Error only when it points at a mod problem: `reason=builderInventoryEmpty` (the lend did not work) or the
  first `unknown` per BaR per session; everything after that at Event (still visible with LogLevel Event).
- Minor, same place: a failed lend (`buildComponentLend`) has already claimed one of the 3 global `proj.Build`
  slots for the tick; check room before claiming, or refund the slot.

## Scenario
SCN-WELD-002 (variant B: DLC-missing block is retried at most once per 5 min, no recurring Error lines).
