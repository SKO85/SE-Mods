# BUG-260612.29: BlockIntersectingZones cache is dead code with a cross-zone-poisonable key

## Status: Open
## Severity: Low
## Version: v2.5.6
## Found In: REVIEW-260612.1 #L13 — `Handlers/SafeZoneHandler.cs:41-45, 386-423, 450`

## Description
`BlockIntersects` is only ever called with `cache: false` (sole caller `GetIntersectingAttackerSafeZone`), so the 15 s `BlockIntersectingZones` cache is never populated and the HUD "block" stat is always 0. Latent bug if ever enabled: the key is `FatBlock.EntityId` only — no zoneId — so a "no intersect" verdict from zone A would be served for a query against zone B.

## Root Cause
Cache built for a usage that never materialized; key designed for a single-zone world.

## Fix
Delete the cache and the `cache` parameter (preferred), or fix the key to include the zone id before any future use.
