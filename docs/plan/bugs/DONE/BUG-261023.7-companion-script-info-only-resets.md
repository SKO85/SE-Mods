# BUG-261023.7: Companion script: info-only mode switches back off on the next automatic run

## Status: Fixed
## Severity: Medium
## Version: v2.5.6
## Found In: REVIEW-261023.1 #7 — `SKO-Nanobot-BuildAndRepair-System-Script/Script.cs:66-71`, `:137-140`, `:163`

## Description
`Main(string arg)` sets `info-only` from the argument on **every** call. The script runs on
`UpdateFrequency.Update100`; automatic runs pass an empty argument, so the next run (~1.7 s later) calls
`SetInfoOnly(false)` and assembler queuing resumes. The documented way to enable it ("set the PB argument
to `info-only` and rerun") therefore only suppresses queuing for one run. (Verify in-game: SE passes an
empty argument for update-frequency runs.)

## Steps to Reproduce
1. Companion script with an assembler group; empty cargo so components are missing.
2. Run the PB with argument `info-only`; status shows "Disabled (info-only)".
3. Within ~2 s status flips back to "Enabled" and assemblers get queue entries.

## Root Cause
Mode is derived from the per-call argument instead of being latched.

## Fix
Implemented.
- `Main` only changes the mode on an explicit argument: `info-only` turns assembler queuing off,
  `queue` turns it back on; automatic Update100 runs (empty argument) leave it alone.
- The mode is stored in the PB `Storage` and restored in the `Program()` constructor, so it survives
  world reloads and recompiles. (Older script versions never wrote `Storage`, so upgrades start in
  the normal queuing mode.)
- Companion-Script doc page: "info-only Mode" section describes `info-only` / `queue`.
- Comments in the script stay ticket-free (player-facing file).

New guard for all script edits: `CompanionScriptTests` compiles `Script.cs` like the game does (C# 6,
wrapped in `MyGridProgram`, default PB usings incl. `VRage.Scripting.MemorySafeTypes`) with the game's
own Roslyn from Bin64; verified it fails on a deliberately broken script. Compile only — the in-game
whitelist is not checked.

Files: `SKO-Nanobot-BuildAndRepair-System-Script/Script.cs`,
`docs/pages/Build-and-Repair-System/Companion-Script/index.md`; tests `CompanionScriptTests.cs` +
two Roslyn HintPath references in the test csproj.

Verification: unit — script compiles. In-game: pending — SCN-API-001 companion step: run with
`info-only`, wait > 10 s (several Update100 runs), status stays "Disabled (info-only)" and no queue
entries appear; reload the world → still info-only; run with `queue` → queuing resumes.
