# BUG-261023.12: Companion script: auto-detect accepts vanilla welders; dead doc link; version strings out of date

## Status: Fixed
## Severity: Low
## Version: v2.5.6
## Found In: REVIEW-261023.1 #12 — `SKO-Nanobot-BuildAndRepair-System-Script/Script.cs:9-10, 293-315`, `SKO-Nanobot-BuildAndRepair-System-Script/metadata.mod`

## Description
- The fallback auto-detection probes `BuildAndRepair.ScriptControlled` / `BuildAndRepair.Mode`, but the
  mod registers its properties on **every** `IMyShipWelder` (Terminal.cs CreateProperty) — vanilla ship
  welders pass the probe and are counted as BaR systems when no group is configured.
- Header link `https://sko85.github.io/SE-Mods/pages/Build-and-Repair-System/Companion-Script/` returns
  404; the live page has no `/pages/` segment.
- Header says v2.5.5, `metadata.mod` says 2.5.4; both need the v2.5.6 bump at release.

## Steps to Reproduce
Fresh world: PB with the script, no BaR group, one vanilla ship welder + one BaR → status counts 2 systems.

## Root Cause
Probe-based detection without a subtype check; URL scheme changed; manual version strings.

## Fix
Implemented.
- Auto-detection fallback first requires the subtype to contain "NanobotBuildAndRepairSystem" (same
  check the mod uses), then probes the properties — vanilla ship welders are no longer counted.
- Header doc link fixed to `https://sko85.github.io/SE-Mods/Build-and-Repair-System/Companion-Script/`
  (old `/pages/` URL returns 404, new one 200 — checked).
- Version: script header `v2.5.6 - 23.10.2026`, script `metadata.mod` 2.5.4 → 2.5.6 (the mod is already
  2.5.6 in `Constants.ModVersion` and its `metadata.mod`). Update the header date at release if needed.

Verification: unit — `CompanionScriptTests` (script compiles). In-game: pending — SCN-API-001 detection
step (no group configured, one vanilla welder + one BaR → 1 system).

SCN-API-001 (detection probe)
