# BUG-260610.41: MsgBlockStateSend swallows all exceptions without logging

## Status: Fixed
## Severity: Low
## Version: v2.5.6
## Found In: REVIEW-260610.1 — `Handlers/NetworkMessagingHandler.cs:509-515`

## Description
The `catch` only stops the profiler; serialization/send failures — including the `GetSyncList` race in BUG-260610.7 — vanish silently while every other send helper logs. Clients silently stop receiving state with no trace.

## Root Cause
Empty catch on the state-send path.

## Fix
Add an error log (throttled if needed) in the catch, matching the other send helpers.

**Resolution:** commit 70c16ef (BuildId 260610.30) on `fix/v2.5.6` - MsgBlockStateSend catch logs ex.Message at Error level instead of swallowing silently. Build: Debug, 0 errors.
