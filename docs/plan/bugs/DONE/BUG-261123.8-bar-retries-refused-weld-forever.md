# BUG-261123.8: A BaR retries a weld the game refuses, every tick, forever

## Status: Done
## Severity: Low
## Version: v2.5.7 (also v2.5.6 and earlier)
## Found In: Torch run 261123.42 / owner, 2026-11-23 (S53: "the BaR keeps trying")

## Description
With the mod's safe-zone check off (`SafeZoneCheckEnabled=false`) and a zone without Welding, the game itself refuses
the weld on a dedicated server: IncreaseMountLevel leaves the integrity unchanged. The BaR does not notice, keeps the
block (and its claim) and retries ~6 times per second: 745 weld calls in 120 s, welding effects, nothing welded. Same for
any other refusal of the weld (protection plugins / mods).

## Fix
After IncreaseMountLevel, no integrity gain on a not-yet-full block = refused: the grid goes on a per-BaR skip list for
30 s (like grinding, BUG-261122.15), the weld counts as failed (assignment released), the loop skips that grid (lock-on
released). The terminal shows "Welding blocked by a safe zone / protection on N grid(s)" (synced `WeldBlockedGrids`,
ProtoMember 26; EN, DE, KO, PL, RU). Profiler: ServerTryWelding `skipRefused`.

## Scenario
SCN-CFG-003 / SCN-ZONE-001 — ingame:S53 (on a DS: <= 5 weld calls in 20 s and the terminal line shown).

## Resolution
Fixed in BuildId 261123.49. Torch S53 (261123.50): 1 weld call in 20 s (was 117), "Welding blocked" shown, nothing
welded, pass.
