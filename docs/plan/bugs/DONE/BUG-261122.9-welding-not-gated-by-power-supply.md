# BUG-261122.9: BaR welds at near full speed when the grid cannot supply its welding power

## Status: Won't Fix (v2.5.6) — deferred to FEAT-261122.3
## Severity: Low
## Version: v2.5.6
## Found In: harness S20 (2026-11-22, 01_211_018, BuildId 261122.11) — `NanobotSystem.Operations.cs:36` (ready = Enabled && IsWorking && IsFunctional), `PowerHelper.ComputeRequiredElectricPower`

## Description
With `Welder.MaximumRequiredElectricPowerWelding` = 100 MW and a single 12 MW battery, one BaR at WorkSpeed 1
welded all 5 damaged blocks in the 30 s window (integrity +10000). It reported unpowered in only 78 samples.

## Root Cause (hypothesis)
The BaR's demand follows its state: standby (powered) → it starts welding and the required input jumps to the
welding power → the game reports it unpowered on the next resource update → `Ready` false, it stops → demand falls
back to standby → powered → it welds again. The weld calls happen in the powered windows, so the power
requirement is not really enforced; the block flickers between working and unpowered.

## Fix (proposed — owner decision)
- (a) Gate each weld/grind call on the supplied ratio for the working demand (e.g. `ResourceSink.SuppliedRatioByType`
  at the welding demand, or `IsPoweredByType` after requesting it), and scale the weld amount by that ratio.
- (b) Keep requesting the working demand for a short hold time after work stops (no flicker), and only weld while powered.
- (c) Accept as is (cheap power balance) and document it.

## Scenario
SCN-CORE-003 (S20: with insufficient power, welding progress must be clearly slower / zero, not full speed).

## Resolution
Owner 2026-11-22: leave as is for v2.5.6 (fix release; no gameplay change). Findings: `PowerHelper.HasRequiredElectricPower`
compares the power for the BaR's *current* state (standby when idle) against the grid's total capacity, so an
under-powered BaR alternates weld / skip and still works at roughly half to full speed. Defaults are 50 kW standby /
200 kW welding (large), so only raised admin requirements or nearly dead grids show it. FAQ entry added
(docs/pages/Build-and-Repair-System/FAQ, "How much power does the system need"). Proportional power: FEAT-261122.3.
