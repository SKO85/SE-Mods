# BUG-260610.4: Safe-zone precheck ignores zone radius and caps at 2 zones — grinding-protection bypass

## Status: Fixed
## Severity: High
## Version: v2.5.6
## Found In: REVIEW-260610.1 — `Handlers/SafeZoneHandler.cs:212-241`

## Description
`GetSafeZonesInRange` prechecks with `Vector3D.Distance(gridCenter, zoneCenter) > range → skip` using fixed `range = 300` and `take = 2`. The zone's radius is never added. A large safe zone (vanilla radius up to 500 m) whose center is >300 m from the grid center but which fully engulfs the grid is filtered out before the precise sphere-vs-AABB test runs. `GetIntersectingSafeZone` (:272) then returns null, caches `zoneId = 0` for 15 s (:329), and `IsProtectedFromGrinding` reports "not protected" → the BaR grinds blocks inside an active safe zone. The `take = 2` cap fails the same way when 3+ zones are within range and the intersecting one is third in dictionary order. Both `GetIntersectingSafeZone` (:272) and `GetIntersectingAttackerSafeZone` (:437) are affected. This silently defeats the fail-closed hardening (BUG-260502.1/2) elsewhere in the file.

## Steps to Reproduce
1. Create a safe zone with radius 400-500 m around a grid; position so the grid center is >300 m from the zone center but inside the zone.
2. Point an enemy BaR (janitor/autogrind) at the grid — it grinds despite the zone.

## Root Cause
Distance precheck does not account for zone radius; arbitrary 2-zone cap.

## Fix
Commit 7dcf588 on `fix/v2.5.6`. `GetSafeZonesInRange`:

- Precheck is now `distance > range + z.Radius + gridRadius`, where `gridRadius` is the grid AABB's half-diagonal — covers both failure directions: a large zone engulfing the grid AND a large grid reaching into a distant zone (the precise test is grid-AABB vs zone-sphere, so grid extent matters symmetrically).
- Removed the `take` cap entirely (parameter dropped; only two callers existed, both using the default) — the intersecting zone may not be among the first few enumerated. Lazy list allocation kept (capacity 4).

Stays consistent with the precise checks (`GridIntersects`/`BlockIntersects`), which treat zones as spheres of `zone.Radius`. BuildId → 260610.3. Build: Debug, 0 errors.
