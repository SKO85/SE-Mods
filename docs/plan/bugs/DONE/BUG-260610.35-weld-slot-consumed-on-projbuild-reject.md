# BUG-260610.35: Weld budget slot consumed even when the proj-build gate then rejects the work

## Status: Fixed
## Severity: Low
## Version: v2.5.6
## Found In: REVIEW-260610.1 — `NanobotSystem.Welding.cs:297, 542`

## Description
`TryClaimWeldSlot` (:297) is claimed before `ServerDoWeld` can still bail at the `TryClaimProjBuildSlot` gate (:542). Under proj-build contention the weld budget is debited for ticks where no weld/build occurred, slightly understating available weld throughput that tick. Cosmetic accounting; directly related to BUG-260610.10 — fixing that one should also resolve or restructure this path.

## Root Cause
Budget claimed before all gates have passed.

## Fix
Fold into the BUG-260610.10 fix: check the proj-build gate before claiming the weld slot, or refund the slot on proj-build rejection.

**Resolution:** commit c8f5f48 (BuildId 260610.24) on `fix/v2.5.6` - new PerTickBudget.Refund() (count only, same-tick) + Mod.RefundWeldSlot(), called from the BUG-260610.10 projBuild-deferred branch. Build: Debug, 0 errors.
