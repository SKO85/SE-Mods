# FEAT-261123.8: Send BaR state only to players near the BaR

## Status: Done
## Priority: Medium
## Version: v2.5.7+
## Requested By: FEAT-261123.7 Torch measurements (2026-11-23)

## Summary
Block state goes to every connected player (SendMessageToOthers), wherever they are. A working BaR sends ~0.4 state
messages per second of ~0.9 KB: 100 working BaRs cost ~32 KB/s per player, so 10 players ~320 KB/s (~2.5 Mbit/s),
peaks ~540 KB/s. Players far away (another base, another planet) do not see the BaR's effects or terminal.

## Motivation
Server bandwidth on multiplayer servers with several bases; most of the state traffic goes to players who cannot see
the BaR.

## Acceptance criteria
- [x] State broadcasts go only to players within the sync distance of the BaR + 500 m (session SyncDistance, fallback
      3 km). Beyond it the client does not have the grid loaded; when it streams in, the block's Init sends a data
      request and gets a full snapshot (existing path), so no terminal special case is needed.
- [x] A player who comes into range gets a full snapshot with the next state send (per-BaR `StateRecipients`).
- [x] Settings broadcasts unchanged (small, rare, needed for the terminal).
- [x] Torch: S126 (BaRs 10 km from the only client: 0 state bytes, `net.state.farSkipped` > 0) and @sync near
      numbers unchanged. Unit: StateRangeTests.

## Implementation notes
Per-BaR send loop over players (MyAPIGateway.Players.GetPlayers, cached list refreshed ~every 2 s), SendMessageTo per
nearby player instead of SendMessageToOthers; track per player the last sent state hash to send a full snapshot on
entering range. Keep the main-thread cost below the current ~0.2 ms per send.

## Testing
SCN-BUDGET-010 — ingame:S70, S106 on Torch with a near and a far client (needs a second client or a fake far player).

## Resolution
Done in BuildId 261123.50. Torch (1 client), 15 / 15 pass: S126 (5 BaRs 10 km away) welded 20 / 20, 0 state bytes to
the client, 8 sends skipped as far (the rest of S126's 0.5 KB/s is the harness's admin profile summary). Near BaRs
unchanged: S70 24.7 KB/s, S106 32.5 KB/s, S43 2.6 KB/s per player, same as 261123.48. Unit: StateRangeTests.
