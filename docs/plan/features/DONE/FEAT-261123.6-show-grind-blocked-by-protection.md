# FEAT-261123.6: Show "Grinding blocked by a shield / protection mod" in the terminal

## Status: Done
## Priority: Medium
## Version: v2.5.7
## Requested By: Steam comment 2026-11-23 ("stopped grinding anything connected to a powered grid with the latest update")

## Summary
Since v2.5.6 the BaR respects BeforeDamage vetoes (shields / protection plugins and mods, BUG-261122.15) and skips a
refused grid for 30 s, silently. Players read that as "the BaR stopped grinding". The terminal now says why.

## Acceptance criteria
- [x] New synced state `GrindBlockedGrids` (ProtoMember 25; count of grids refused within the last 30 s), set before
      the exhausted-skip in ServerTryGrinding, part of the state hash.
- [x] Terminal line "Grinding blocked by a shield / protection mod on {0} grid(s)" (EN, DE, KO, PL, RU).
- [x] S74 (damage-handler protection) asserts the BaR shows it (`grindBlockedShown >= 1`); S73 / @grind unchanged.

## Testing
SCN-GRIND-006 — ingame:S74 (new check), S73.

## Resolution
Done in BuildId 261123.42. S74: BaR showed GrindBlockedGrids = 1 while the protection handler refused (1 refusal, 1 grind
call, 10/10 blocks left intact). Release notes v2.5.7.
