# FEAT-261123.7: Network traffic counters and sync-load tests for dedicated servers

## Status: Done
## Priority: Medium
## Version: v2.5.7
## Requested By: owner, 2026-11-23 ("tests for performance on Torch and the amount of data and syncing, to avoid spikes")

## Summary
Measure what the mod sends and receives per message type on a server, and test that the sync stays bounded.

## Acceptance criteria
- [x] `Handlers/NetStats`: per message type messages, payload bytes, wire bytes (x recipients), largest message,
      received messages / bytes; every send goes through SendTo / SendToOthers / SendToServer, every receive handler
      counts. Array adds under a lock, no allocation per message.
- [x] Harness: `net.*` metrics on every scenario (snapshot at run start), `ctx.NetSent(msgId, ...)`, `ctx.RemotePlayers()`.
- [x] S116 (settings churn, 20 BaRs), S117 (512-entry target list) and S118 (50 idle BaRs) with traffic checks when a client is connected;
      `@sync` group (S43, S70, S106, S111, S116, S117).
- [x] Per-second traffic peaks on every scenario (`net.peakKBps`, `net.peakMsgsPerS`, `net.peakAtS`).
- [x] Grid-size series S119-S123 (100 / 1,000 / 3,000 / 8,000 blocks, then all four) for CPU + traffic spikes.
- [x] First Torch run: tune the envelopes (64 KB state message, 1 send per BaR per s) from the data.

## Testing
SCN-BUDGET-010 — unit:NetStatsTests; ingame:S116, S117 (Torch).

## Resolution
First Torch run (BuildId 261123.48, 1 admin client, world welder / grinder speed 2): `@sync` + S53, S64-S67, S107, S108,
20 / 20 pass.

| Scenario | BaRs | avg KB/s per player | peak KB/s | state msgs per BaR per s | avg / largest state msg |
|---|---|---|---|---|---|
| S43 (4,000-block ship) | 5 | 2.6 | 5.3 | 0.42 | 1.0 / 1.2 KB |
| S70 (mixed load) | 40 | 24.7 | 39.6 | 0.41 | 1.5 / 2.1 KB |
| S106 (logistics) | 100 | 31.7 | 53.9 | 0.39 | 0.8 / 1.2 KB |
| S116 (settings toggled 2x/s) | 20 | 7.0 | 20.2 | 0.27 (settings 0.89) | 0.8 / 1.1 KB |
| S117 (512-entry target list) | 1 | 1.0 | 2.2 | 0.50 | 1.0 / 1.1 KB |
| S118 (idle) | 50 | 0.4 | 3.4 | 0.00 | - |
| S119-S123 (100 ... 12,100 blocks) | 10 | 1.3-1.9 | 6.4-8.8 | 0.14-0.15 | 0.5-0.9 / 1.1 KB |

Findings: messages are small (largest 2.1 KB; the target lists do not go out in full), idle costs nothing, settings
spam is held to < 1 per BaR per s. Traffic grows with working BaRs: ~0.3-0.6 KB/s per working BaR per player, sent to
every player wherever they are (100 working BaRs x 10 players ~ 320 KB/s). CPU by grid size (S119-S123): tick avg
0.017 / 0.026 / 0.048 / 0.107 / 0.121 ms for 100 / 1k / 3k / 8k / 12.1k blocks, peaks < 0.6 ms.
