# FEAT-261123.3: Pull more components per conveyor transfer

## Status: On hold (re-measure first)
## Priority: Low
## Version: v2.5.7+

## Summary
Pull more components per conveyor transfer.

## Motivation
`TransferItemFrom` is 88 % of the pull cost, about one pull per welded block.

## Design
Pull 4-8x the current need into the BaR's own inventory per transfer (bounded by volume). Roughly halves the pull
cost (0.5-2.5 ms/s). Behaviour change (BaRs hold more stock; interacts with push options and other BaRs' supply) —
owner decision needed.

## Testing
SCN-INV-001 — ingame:S103-S110 (pull ms/s, plates conserved), S86, S90-S93.
## Owner decision (2026-11-23)
Re-measure the pull cost first (S105 / S106 `detail` on a build with BUG-261123.6, which cut weld attempts ~20x), then
decide. Only if the pull still costs a noticeable share: a bounded variant (2-4x the need, capped by free volume, only
from well-stocked sources).
