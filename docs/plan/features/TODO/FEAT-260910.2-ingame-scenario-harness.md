# FEAT-260910.2: In-game scenario test harness (`/nanobars test`), Testing variant only

## Status: In Progress
## Priority: High
## Version: v2.5.6
## Summary
Server-side scenario runner inside the mod: spawns a test rig, configures BaRs, runs for N seconds,
asserts functional results and profiler/tick-cost numbers, tears down, reports to chat and
`NanobotTest.<session>.log`. Ships only in the `-Testing` mod variant via the
`_Scripts/BuildAndRepairSystem/Testing/` overlay.

## Motivation
A programmable block can configure/observe a BaR but cannot spawn grids, damage blocks, fill cargo,
run chat commands or see performance (`MethodProfiler` is internal). Mod code can. Perf regressions
like #143 need repeatable in-game runs with numbers, not hand-driven profiling sessions.

## Design
Release-side seam (~15 lines):
- `Mod.cs`: `public static Action TestTick; public static Func<string[], ulong, ChatCommandResult> TestCommand;`
  called after `CleanupFriendlyDamage()` in the server branch of `UpdateBeforeSimulation`; nulled in `UnloadData`.
- `Chat/ChatHandler.cs` `ExecuteServerCommand`: `case "test"` → `Mod.TestCommand` or
  "Test harness not installed (Testing variant only)".
- `Profiling/MethodProfiler.cs`: `MethodStatsSnapshot` + `internal static bool TryGetMethodStats(name, out snapshot)`.
- csproj: linked `<Compile Include="..\..\..\..\_Scripts\BuildAndRepairSystem\Testing\Data\Scripts\...\Testing\**\*.cs">`
  so the harness compiles under LangVersion 6 but is never copied into the base/Original variants.

Harness (`_Scripts/BuildAndRepairSystem/Testing/Data/Scripts/SKO-Nanobot-BuildAndRepair-System/Testing/`):
`TestHarnessComponent` (session component, assigns the delegates), `TestCommand`
(`test list | run <id|all> [xN] | status | abort | origin x y z`), `TestRunner` (main-thread state machine
Idle→Setup→WaitReady→WarmUp→Run→Assert→Teardown→Report), `TestContext` (spawn/stock/damage/configure
primitives, metrics, checks), `TestIsolation` (static handler resets + `Mod.Settings` XML snapshot/restore),
`RigBuilder` (code-built `MyObjectBuilder_CubeGrid` rigs), `Scenarios/ITestScenario` + `TestScenarioBase`,
`S01..S09`, `ScenarioRegistry` (static array, no reflection). `Data/Prefabs/NanobotTest_BigShip.sbc` for S08.

Report: `NanobotTest.<yyyyMMddHHmmss>.log` in local storage, `key=value;` lines
(`result=`, `fail=`, `agg=` min/avg/max over repeats, `summary=`), plus one chat line per run.

First scenarios: S01 RepairStocked, S02 RepairEmptyCargo, S03 ProjectedBuild, S04 JanitorGrind,
S05 NoDoubleAssign, S06 MaxSystemsPerGrid, S07 ClusterOneScanner, S08 LargeGridPerf (#143),
S09 ScriptingContract (PB, optional). Catalogue ids in `docs/plan/scenarios/`.

ModAPI calls to verify in-game first: `CreateFromObjectBuilderAndAdd` with a code-built grid (BaR logic
init, battery power), `GetPrefabDefinition`+`Clone` whitelist (fallback `IMyPrefabManager.SpawnPrefab`),
`DecreaseMountLevel`/`SetToConstructionSite` scan pickup, `IMyProjector.SetProjectedGrid`+`ProjectionOffset`,
`AddItems` with `MyObjectBuilder_Component`, `ProgramData` recompile, DS owner lookup by SteamId.
