# FEAT-261123.1: Cheaper per-block scan checks

## Measured (detail run S43 / S66 / S67 / S70, BuildId 261123.34)
AsyncAddBlocksOfGrid on a 4,028-block grid (S43): 12.3 ms avg, 26 ms max (~3 us per block); cluster scan 16 ms avg,
35 ms max. Applying results 0.5-2 ms avg, 14 ms max. All on background threads, so no frame time; the gain is quicker
target pickup and less background CPU on servers with many BaRs. Priority: after BUG-261123.3.

## Status: In progress (safe parts built, measuring)
## Priority: High
## Version: v2.5.7+

## Summary
Cheaper per-block scan checks.

## Motivation
The scan costs ~1.1 µs per block (S99-S102: 11.5 ms for 10,000 blocks), ~95 % of it mod code for intact blocks.

## Design
- Call `HasDeformation` only when `MaxDeformation > 0` (likely the biggest cut). In-game check first: does a dent
  survive save / reload? Otherwise dented blocks would be missed after a restart.
- Read integrity / deformation once (merge the NeedRepair pass and the deformation branch).
- Hoist per-grid checks (IsProjected) out of the block loop; read the colour only when a colour option is on.
- Janitor: integrity tests before the relation lookup; remember the relation per grid + owner.
Target <= 0.5 µs per block.
