# FEAT-260910.3: Local xUnit project for the pure core (no CI)

## Status: In Progress (first wave landed 2026-10-23, 96 tests green)
## Priority: Medium
## Version: v2.5.6
## Summary
`tests/SKO-Nanobot-BuildAndRepair-System.Tests/` — net48 xUnit project that tests the compiled mod
assembly out of game, against the Space Engineers assemblies from `$(SpaceEngineersBin)`. Runs on any dev
box with Space Engineers installed (`dotnet test`). No CI: the SE assemblies are licensed and cannot go on
a hosted runner.

## Motivation
Fast local feedback for the logic with real bug history: TtlCache cleanup (BUG-003/260522.3), per-tick
budgets (BUG-260610.35), settings clamp/migration (BUG-260511.12, BUG-093), config bounds and invariant
parsing (BUG-260610.20), QuickSelect (FEAT-074), stagger thresholds (BUG-031), plus guards that catch
whole bug classes: ProtoBuf tag uniqueness (network sync) and translation key parity.

## Design (as built — supersedes the original seam plan)
**Zero changes to mod code.** The original plan needed five seams (Logging guard, PerTickBudget frame
counter, stagger extraction, network guard, `InternalsVisibleTo`). None are needed:
- Every engine static the mod touches is publicly settable — `MyAPIGateway.Session` (property),
  `Utilities/Physics/Players/Parallel/Multiplayer` (public fields), `MyLog.Default` (public setter) —
  so `ModTestBase` injects an NSubstitute `IMySession` with controllable `ElapsedPlayTime` /
  `GameplayFrameCounter` and nulls the rest.
- Private members (QuickSelect, `_cachedAutoStagger`, `_Welder`, `CurrentSettingsVersion`, internal
  handlers) are reached via reflection — allowed in test code; only mod code is sandboxed.
- No `InternalsVisibleTo` also removes the risk of an assembly attribute reaching SE's script compiler.

Isolation from the existing build:
- `tests/Directory.Build.props` (SE path property) and `tests/nuget.config` (nuget.org only — the dev
  machine's global config has private feeds that 401) apply to the test project only.
- Mod csproj, `SKO-SE-Mods.sln`, `_Scripts/**` untouched. Building the tests builds the mod via
  ProjectReference, which runs the normal post-build deploy (verified identical deployed file set).
- Serial execution (`DisableTestParallelization`); mod statics reset before/after each test.
