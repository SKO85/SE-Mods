# FEAT-260910.3: Local xUnit project for the pure core (no CI)

## Status: Proposed
## Priority: Medium
## Version: v2.5.6
## Summary
`tests/SKO-Nanobot-BuildAndRepair-System.Tests/` — net48 xUnit project referencing the mod project and
the SE assemblies through a shared `$(SpaceEngineersBin)` MSBuild property. Runs on any dev box with
Space Engineers installed. No CI: the SE assemblies are licensed and cannot go on a hosted runner; the
game-free surface (~4 trivial helpers) is not worth a second project.

## Motivation
Fast local feedback for the logic with real bug history: TtlCache two-pass cleanup (BUG-003/260522.3),
per-tick budgets (BUG-260610.35), settings clamp/migration (BUG-260511.12, BUG-093), config bounds
(BUG-260610.20), QuickSelect/fair-share truncation (BUG-027), stagger thresholds (BUG-031).

## Design
Seams (C# 6, ≤6 lines each, no in-game behaviour change):
- S1 `Utils/Logging.cs:126` — guard `MyLog.Default != null` (null outside the game; first thing `Logging.Instance` hits).
- S2 `Managers/PerTickBudget.cs` — optional `Func<int> frameCounter` ctor arg; `:59` uses it when set.
- S3 `Mod.cs:118-121` — extract `internal static int AutoStaggerGroupsFor(int enabledCount)`.
- S4 `Handlers/NetworkMessagingHandler.cs:397` — `MyAPIGateway.Session == null ||` in the early return.
- S5 `QuickSelect` → `internal static`; later `TruncateGridAware` → `internal`; `Properties/AssemblyInfo.cs`
  with `InternalsVisibleTo("SKONanobotBuildAndRepairSystem.Tests")` — whitelist-safe because
  `build_post.cmd:13` deletes `Properties\` from the deployed mod (verify after first build).
Build wiring: root `Directory.Build.props` defines `SpaceEngineersBin` (env `SPACEENGINEERS_BIN`, else
`E:\SteamLibrary\steamapps\common\SpaceEngineers\Bin64`); mod csproj HintPaths → `$(SpaceEngineersBin)\X.dll`.
Test project: `net48`, `PlatformTarget x64` (SE DLLs are AMD64), xUnit + NSubstitute, assembly-level
`CollectionBehavior(DisableTestParallelization = true)`, `ModStaticsFixture` base resetting `Mod.Settings`,
`Mod.NowPlayTime` (non-zero), `NanobotSystems`, `GridSystemCount`, `SimSpeedOverride`, handler caches.
First tests: TtlCache (3), PerTickBudget (4), SyncModSettings clamp/fold/migrate (3), Mod resolvers (2),
QuickSelect vs sort (1), ConfigCommand round trip/bounds (1), collections/WrapText/GridSaturationTracker (3).
Second wave: TruncateGridAware (needs `new NanobotSystem()` outside the game — verify, don't refactor).

## Files Affected
New: `Directory.Build.props`, `tests/.../*.csproj`, `AssemblyInfo.cs`, `ModStaticsFixture.cs`, test classes;
