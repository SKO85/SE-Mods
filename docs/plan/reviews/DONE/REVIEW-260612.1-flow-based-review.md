# REVIEW-260612.1: Flow-based review — welding, grinding, collecting, transport/inventory, safe zones, shields

## Status: Done
## Reviewer: AI (six parallel flow agents; top findings re-verified against source)
## Date: 2026-06-12
## Version: fix/v2.5.6 @ BuildId 260610.40 (post REVIEW-260610.1 fix pass)

## Summary

Second full review, sliced by flow instead of by file, with explicit regression-checking of the 43-ticket fix pass. The fix pass itself held up well — only one real regression interaction surfaced (H1, .21's effective-id counting vs an old raw-id consumer). The big new themes are: **safe-zone/shield enforcement is scan-time only** (every cache TTL is a real action window), **box-shaped safe zones are mishandled everywhere**, welding lacks a target-side zone check entirely, and the transport flow has one verified item-destruction path. Verified by me directly: H1, H2 (plus SZ box-sphere geometry corroborated from earlier reads); the rest carry agent-verified file:line evidence, several found independently by two agents.

| H7 | Shields | **`GridScanCache` shares entries across home grids while grind filters are home-grid-dependent** (`Scanning.Block.cs:340-343` excludes home grid from the params hash; own-grid shield exemptions at :278 and `State.cs:72`). Narrow preconditions, real inversion both ways. Medium-high. Fix: factor "target grid == home grid" into the cache key/lookup. | bug 260612.7 |

### Dismissed / accepted

- **MaxDeformation visual repair loss** (weld flow) — the deliberate, documented BUG-260610.5 trade-off chosen on 2026-06-10; queue design on file if players report it.
- **Floating list not preserving `Ignore` across rescans** — intentional/safe (emptied floats leave the world; scan filters emptied corpses).

## Recommendations

- Fix H1 immediately — it's a regression interaction that degrades projection welding at the per-grid limit, the exact scenario .21 was meant to protect.
- H3+H4+H6 are one theme (zone semantics): box-shape support, target-side weld check, and any-zone-prohibits aggregation could land as one SafeZoneHandler pass; M6's execution-time gates complete it.
- H5 and M4 are one-liners; H2/M1/M5 are the transport-correctness cluster and should be fixed together (shared root: transport-inventory volume accounting).
- All recommendations are allocation-conscious; nothing here adds per-tick work beyond two flag checks in the execution gates.
